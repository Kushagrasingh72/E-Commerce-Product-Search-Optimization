E-Commerce Product Search Optimization - DAA Project

Files:
- app.py: Streamlit application
- products.csv: 300 sample product rows
- requirements.txt: required packages

Run:
1. Install Python
2. Open terminal in this folder
3. pip install -r requirements.txt
4. streamlit run app.py

Algorithms covered:
- Linear Search (keyword search)
- Binary Search (price lookup)
- Merge Sort (sorting benchmark)
- Filtering and complexity comparison
